# Pip Job Search installers

Downloads for **Pip Job Search**, a desktop app that finds jobs that fit you, scores every one, and writes a tailored CV and cover letter for the ones you pick. Pip, the app's guide, walks you through it.

Get it from the website, or from the [latest release](https://github.com/Zanatti/job-search-releases/releases/latest):

- **Mac** (Apple silicon, macOS 13 or later): `Pip-Job-Search-mac.dmg`
- **Windows** (10 or 11, 64-bit): `Pip-Job-Search-Windows-Setup.exe`

You need a Claude Pro or Max plan, or a ChatGPT Plus or Pro plan. The app is free.

This repository only holds the installers.
